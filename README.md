# Wesley Telles — Portfólio

Portfólio pessoal em HTML, CSS e JavaScript, com animações em GSAP, scroll suave com Lenis e glifos 3D em Three.js. Português por padrão, com botão para inglês.

Acesse: [portfoliotelles.netlify.app](https://portfoliotelles.netlify.app)

## Rodar localmente

Os caminhos são absolutos, então é preciso um servidor HTTP:

```
npx serve .
```

## Páginas

Home, sobre, projetos (FIO, Nolinha, Tipsteria, BUCK e AX Charge), conquistas e contato.
